# Report LaTeX source

The main report is report.tex. Upload this directory to Overleaf and choose report.tex with pdfLaTeX, or run `tectonic report.tex`. The report preserves the Group-11 author details, inline tables and `artifacts/` folder layout from the uploaded current source. All required figures and IEEEtran.cls are in `artifacts/`.

The seven-page report uses the IEEE conference layout. It introduces the baseline, explains the gap and intuition behind each proposed idea, describes the implementation and setup, then presents results in Evaluation.

The other two TeX files produce the separate baseline and contribution result PDFs using `figures/` and `tables/`. Complete result sources and unused exploration plots remain available in those directories.
