# Report LaTeX source

The main report is report.tex. Upload this directory to Overleaf and choose report.tex with pdfLaTeX, or run `tectonic report.tex`. IEEEtran.cls, tables and vector PDF figures are included.

The report uses the IEEE conference layout. It introduces the baseline, describes our design and setup, then presents results in Evaluation. The author label is CS5290 Project Group.

The other two TeX files produce the separate baseline and contribution result PDFs.
